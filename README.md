# 🐾 Plataforma de Adoção e Serviços para Animais
> Projeto prático desenvolvido para a disciplina de Banco de Dados Não Relacionais e Inteligência de Dados na **FATEC Osasco**.

## 📌 Aluna
- **Nome:** Geovana Souza Corrêa
- **Orientador:** Prof. Vander Ribeiro Elme

## 🎯 Escopo do Projeto
- **Arquitetura NoSQL:** Documentos (MongoDB), Chave-Valor (Redis) e Grafos (Neo4j).
- **Escalabilidade & Teorema CAP:** Estratégias AP (Sessões) e CP (Catálogo).
- **Inteligência de Dados:** Modelagem Dimensional em Esquema Estrela (DW) e Mineração de Dados (Clustering & Regras de Associação).
- **Governança & LGPD:** Hardening de infraestrutura e Direito ao Esquecimento via pseudonimização.
